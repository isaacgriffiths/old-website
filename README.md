# Old isaacgriffiths.com

The first version of my personal site: a single hand-written HTML page with one stylesheet, no build step and no framework. Kept for the record.

The site that is live at [isaacgriffiths.com](https://isaacgriffiths.com) today is a Next.js rebuild. Its source is in [current-website](https://github.com/isaacgriffiths/current-website).

- Inter typography, a custom cursor with a light effect on desktop, and social links drawn as inline SVG.
- Responsive without a framework. The cursor effect is switched off on touch devices.

## Running this version

Open `index.html` in a browser. There is nothing to install.
